# Gagauzium

Gagauzium — приложение для изучения гагаузской лексики по тематическим категориям. Оно написано на Python с помощью [Flet](https://flet.dev/) и в первую очередь предназначено для Android, но во время разработки запускается и как настольное приложение.

Интерфейс доступен на русском и румынском языках. Текущий словарь содержит **920 слов и выражений в 25 категориях**.

## Возможности

### Изучение новых слов

- тематические категории с отдельным прогрессом;
- небольшие учебные серии до 6 новых слов;
- карточки с переводом и навигацией вперёд/назад;
- проверка перевода каждого слова после просмотра карточек;
- дополнительные задания «Да / Нет» и «Составление слов»;
- финальное сопоставление всех слов серии с переводами;
- автоматическое сохранение последней активной категории.

### Повторение

На экране «Повторять» доступны восемь режимов:

1. **Ежедневное повторение** — 20 слов, включая 5 слов с наибольшим числом ошибок. Открывается после изучения 20 слов и сохраняет незавершённую сессию.
2. **Сложные слова** — слова, в которых пользователь ошибался. Слово перестаёт требовать внимания после двух правильных ответов подряд в этом режиме.
3. **Обычное повторение** — выбор правильного перевода в обоих направлениях.
4. **Быстрое повторение** — задания с таймером, тремя жизнями и сохранением лучшего результата.
5. **Составление слов** — сборка гагаузского слова из букв с лишними вариантами. Для записей с вариантами через `/` собирается первый вариант, пояснения в скобках не собираются, пробелы и дефисы уже стоят на своих местах, а для длинных слов показываются начальные подсказки. В повторении используются слова длиной до 12 букв.
6. **Да / Нет** — проверка предложенного перевода; неправильный вариант дополнительно требует выбрать правильный перевод.
7. **Найди пары** — сопоставление гагаузских слов с русскими или румынскими переводами блоками по 5 пар.
8. **Большое повторение** — смешанная тренировка с обычными вопросами, составлением слов, заданиями «Да / Нет» и поиском пар.

Базовые режимы повторения открываются после 4 изученных слов, «Найди пары» — после 5, «Большое повторение» — после 10, ежедневная сессия — после 20. Для режима сложных слов нужна хотя бы одна изученная запись, отмеченная как требующая внимания.

### Прогресс

- взвешенная подборка: слова с ошибками и давно не встречавшиеся слова появляются чаще;
- похожие неправильные варианты: в выборе перевода два из трёх неверных вариантов относятся к той же части речи (по возможности из той же темы), третий выбирается случайно; в «Да / Нет» неверный перевод похож на правильный в двух случаях из трёх; другие правильные переводы омонимов никогда не предлагаются как ошибка;
- общий и категорийный прогресс;
- список десяти самых сложных слов;
- серия дней с завершёнными занятиями;
- отдельный экран достижения рубежа в 50 изученных слов;
- сохранение языка, результатов, рекордов и прогресса между запусками;
- просмотр всех слов выбранной категории;
- сброс прогресса отдельной категории с подтверждением: статус изучения и статистика ответов её слов обнуляются, а ещё не пройденные слова категории убираются из сегодняшнего ежедневного повторения;
- полный сброс изученных слов, статистики ответов, ежедневной сессии и серии занятий.

## Текущее состояние уровней

В `words_data.json` уже есть поля `level` со значениями `beginner` и `conversational`. Сейчас приложение не фильтрует словарь по уровню: в интерфейсе активен начальный уровень, а остальные уровни показываются как заблокированные элементы.

В каталоге [`docs/curriculum-proposal/`](docs/curriculum-proposal/) находится предложение будущей структуры из 42 тем, внутренних блоков и правил открытия уровней. Это исследовательская документация, а не реализованная логика приложения.

## Требования

- Python 3.12–3.14;
- Flet 0.86.5 — версия зафиксирована в `pyproject.toml`.

Для сборки Android-приложения также нужны JDK 17 и Android SDK. Если они отсутствуют или имеют несовместимую версию, Flet CLI устанавливает подходящие инструменты при первом запуске `flet build`.

## Локальный запуск

Клонируйте репозиторий и перейдите в его каталог:

```bash
git clone https://github.com/evghenbozbei/gagauzium.git
cd gagauzium
```

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его.

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

macOS и Linux:

```bash
source .venv/bin/activate
```

Установите проект и зависимости:

```bash
python -m pip install --upgrade pip
python -m pip install .
```

Запустите приложение:

```bash
python main.py
```

Для запуска через Flet CLI с режимом разработки можно использовать:

```bash
flet run main.py
```

## Сборка Android

Flet позволяет собирать Android-приложение на Linux, macOS и Windows. Ни Flutter, ни Android Studio заранее устанавливать не обязательно: Flet CLI может самостоятельно подготовить JDK 17 и Android SDK. Для первой сборки нужны интернет-соединение и свободное место на диске.

Текущие параметры приложения находятся в [`pyproject.toml`](pyproject.toml):

- версия приложения — `1.0.4`;
- номер сборки — `6`;
- bundle ID — `com.flet.gagauzium`.

### Подготовка на Ubuntu

Установите базовые инструменты:

```bash
sudo apt update
sudo apt install -y git python3 python3-venv python3-pip
```

Клонируйте проект, создайте виртуальное окружение и установите зависимости:

```bash
git clone https://github.com/evghenbozbei/gagauzium.git
cd gagauzium
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install .
```

### APK

Проверьте окружение и соберите release APK:

```bash
flet doctor
flet build apk
```

Первая сборка может занять заметно больше времени из-за загрузки Android-инструментов и шаблона Flutter. Готовый APK появляется в каталоге:

```text
build/apk/
```

По умолчанию создаётся один универсальный APK для поддерживаемых архитектур. Для отдельных APK меньшего размера используйте:

```bash
flet build apk --split-per-abi
```

### Установка APK на устройство

Включите на телефоне режим разработчика и отладку по USB, подключите устройство и проверьте соединение:

```bash
adb devices
```

Установите APK:

```bash
adb install build/apk/gagauzium.apk
```

APK также можно передать на телефон и открыть файловым менеджером, разрешив установку приложений из используемого источника.

### Android App Bundle и подпись

Для Google Play предпочтителен формат Android App Bundle:

```bash
flet build aab
```

Результат сохраняется в `build/aab/`. Для публикации нужен собственный upload keystore. Если он не настроен, release-сборка подписывается debug-ключом: такой файл подходит для локального тестирования, но не для Google Play.

В [`.env.example`](.env.example) перечислены переменные подписи. Скопируйте файл в `.env`, задайте абсолютный путь к своему keystore и не добавляйте `.env` или файлы ключей в Git:

```bash
cp .env.example .env
```

Подробности и актуальные параметры находятся в [официальной инструкции Flet для Android](https://flet.dev/docs/publish/android/).

## Как устроено обучение

При первом запуске приложение предлагает выбрать русский или румынский язык интерфейса.

1. Откройте вкладку «Учить» и выберите тематическую категорию.
2. Нажмите «Начать обучение». Приложение выберет до 6 неизученных слов.
3. Просмотрите карточки. На последней карточке начнётся проверка знаний.
4. Выберите правильный перевод каждого слова. Правильный ответ отмечает новое слово как изученное.
5. Выполните дополнительные задания «Да / Нет» и «Составление слов».
6. Соедините все слова серии с переводами в финальном задании «Найди пары».
7. После результатов продолжайте категорию или используйте один из режимов повторения.

Обычная сессия повторения категории содержит до 6 слов, а общее повторение — до 10. Набор ежедневного повторения фиксируется на текущую дату и продолжается с сохранённой позиции, если закрыть приложение до завершения.

```text

├── assets/
```

Рабочая реализация находится в `main.py` и использует Flet. Исследовательские материалы из `docs/` хранятся в Git, но вместе с локальными служебными каталогами исключены из APK через секцию `[tool.flet.app]` в `pyproject.toml`.

## Формат словаря

Каждая запись в `words_data.json` имеет следующий вид:

```json
{
  "id": 1,
  "ru": "я",
  "ro": "eu",
  "gag": "bän",
  "category": "Местоимения",
  "level": "beginner",
  "part_of_speech": ["pronoun"],
  "learned": false
}
```

- `id` — уникальный стабильный идентификатор; текущий диапазон — 1–920;
- `ru`, `ro`, `gag` — русский, румынский и гагаузский варианты;
- `category` — исходное имя категории, совпадающее с `source_name` в `category_metadata.py`;
- `level` — подготовленный уровень сложности, пока не используемый для фильтрации интерфейса;
- `part_of_speech` — одна или несколько частей речи;
- `learned` — контентное значение всегда `false`; реальный прогресс хранится отдельно.

Не переиспользуйте существующие ID, сохраняйте JSON в UTF-8 и проверяйте, что все категории присутствуют в [`category_metadata.py`](category_metadata.py).

## Пользовательские данные

Прогресс хранится отдельно от словаря. `user_stats.json` содержит:

- выбранный язык;
- последнюю активную категорию;
- статус изучения каждого слова;
- количество правильных и неправильных ответов;
- дату последнего появления слова;
- признак сложного слова и серию правильных ответов для его закрепления;
- ежедневную подборку и текущую позицию в ней;
- серию дней занятий;
- лучший результат быстрого повторения;
- показанные достижения.

При прямом запуске через `python main.py` файл находится рядом с исходниками и не хранится в Git. Если задана переменная `FLET_APP_STORAGE_DATA`, используется указанный каталог. В собранном Android-приложении Flet помещает файл в приватное постоянное хранилище приложения.

Данные сохраняются при обновлении приложения с теми же bundle ID и подписью, но удаляются при удалении приложения или очистке его данных. Облачной синхронизации сейчас нет.

## Данные словаря и ограничения

Текущий словарь расширен с 750 до 920 записей. Материалы проверки и происхождения новых слов находятся в [`docs/linguistic-audit/`](docs/linguistic-audit/). Важно учитывать ограничения:

- база полностью не проверена носителем гагаузского языка;
- совпадение с источником не заменяет человеческую лингвистическую проверку;
- румынские переводы новых записей требуют отдельной проверки;
- варианты через `/`, возможные дубли и предложенные исправления вынесены в файлы аудита;
- предложения из `docs/` не применяются автоматически к приложению.

Отдельное предложение по перераспределению всех 920 ID по темам и уровням находится в [`docs/curriculum-proposal/analysis_report.md`](docs/curriculum-proposal/analysis_report.md). До утверждения оно не меняет `words_data.json`, категории или пользовательский прогресс.

## Разработка и проверки

Основная логика пока сосредоточена в `main.py`; метаданные категорий вынесены в `category_metadata.py`. Чистые функции учебной логики находятся на уровне модуля и покрыты тестами.

Установите зависимости для разработки и запустите тесты перед коммитом:

```bash
python -m pip install -e ".[dev]"
python -m pytest
```

Тесты в `tests/test_words_data.py` проверяют словарь:

- уникальность ID и заполненность `ru`, `ro`, `gag` без лишних пробелов;
- соответствие категорий `category_metadata.py`;
- сохранение `learned: false` в контентной базе;
- алфавиты: гагаузские `ş`/`ţ` с седилем, румынские `ș`/`ț` с запятой снизу, отсутствие латинских букв в русском тексте;
- возможность собрать каждое слово в «Составлении слов» и наличие неправильных вариантов ответа для каждого вопроса.

Записи, которые ждут проверки носителем языка, перечислены в `UNVERIFIED_GAGAUZ_CHARACTERS`. Тесты в `tests/test_logic.py` покрывают прогресс, серию дней, подборки слов, варианты ответов и сохранение статистики; они никогда не трогают настоящий `user_stats.json`.
