# Gagauzium

Gagauzium — Android-приложение для изучения гагаузской лексики, написанное на Python с помощью Flet. Оно помогает учить слова по тематическим категориям, повторять сложные слова и отслеживать личный прогресс.

Основная целевая платформа проекта — Android. Благодаря Flet приложение можно запускать на компьютере во время разработки, а затем собирать в APK без переписывания интерфейса на Dart.

Интерфейс доступен на русском и румынском языках. В словаре сейчас 750 слов в 25 категориях.

## Возможности

- изучение новых слов небольшими сессиями по 6 слов;
- повторение выученных слов по отдельной категории или по всему словарю;
- вопросы в обоих направлениях: с русского/румынского на гагаузский и обратно;
- взвешенная подборка: слова с большим числом ошибок и давно не встречавшиеся слова появляются чаще;
- ежедневное повторение из 20 слов, включая 5 самых сложных;
- быстрое повторение с таймером и тремя жизнями;
- режим «Правда или ложь» на 15 вопросов;
- статистика общего прогресса и список десяти самых сложных слов;
- просмотр всех слов выбранной категории;
- сохранение языка, результатов и прогресса между запусками;
- сброс прогресса отдельной категории или всего словаря с подтверждением.

## Требования

- Python 3.12–3.14;
- [Flet](https://flet.dev/).

Для сборки Android-приложения также нужны JDK 17 и Android SDK. Если они не установлены, актуальная версия Flet CLI автоматически загрузит совместимые инструменты при первой сборке.

## Локальный запуск для разработки

Клонируйте репозиторий и перейдите в его каталог:

```bash
git clone <URL-репозитория>
cd gagauzium
```

При желании создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его.

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

macOS и Linux:

```bash
source .venv/bin/activate
```

Установите зависимости проекта и запустите приложение из его корня:

```bash
python -m pip install .
python main.py
```

Словарь загружается из файлов приложения, а пользовательский прогресс сохраняется отдельно в постоянном хранилище Flet.

## Сборка APK на Ubuntu

Собирать Android-версию удобнее всего на Linux. Ни Flutter, ни Android Studio заранее устанавливать не обязательно: Flet CLI может самостоятельно подготовить JDK 17 и Android SDK. Для первой сборки понадобятся интернет-соединение и свободное место на диске.

Установите базовые инструменты:

```bash
sudo apt update
sudo apt install -y git python3 python3-venv python3-pip
```

Клонируйте проект, создайте виртуальное окружение и установите Flet:

```bash
git clone <URL-репозитория>
cd gagauzium
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install .
```

Проверьте окружение и соберите release APK:

```bash
flet doctor
flet build apk
```

Первая сборка может занять заметно больше времени, поскольку Flet загружает Android-инструменты и шаблон Flutter-проекта. Готовый файл появится в каталоге:

```text
build/apk/
```

Чтобы найти точное имя артефакта:

```bash
find build/apk -type f -name "*.apk"
```

По умолчанию создаётся один универсальный APK для поддерживаемых архитектур Android. Он удобен для установки вручную, но имеет больший размер. Для отдельных APK меньшего размера можно выполнить:

```bash
flet build apk --split-per-abi
```

### Установка APK на устройство

Включите на телефоне режим разработчика и отладку по USB, подключите устройство и проверьте соединение:

```bash
adb devices
```

Затем установите собранный файл:

```bash
adb install <путь-к-файлу.apk>
```

Также APK можно передать на телефон и открыть обычным файловым менеджером, разрешив установку приложений из этого источника.

### Сборка для Google Play

Для публикации в Google Play предпочтителен формат Android App Bundle:

```bash
flet build aab
```

Результат будет сохранён в `build/aab/`. Для загрузки в Google Play потребуется собственный upload keystore и release-подпись. Локальная APK-сборка без настроенного keystore подписывается отладочным ключом: её можно установить для тестирования, но нельзя публиковать в магазине.

Подробности и актуальные параметры сборки находятся в [официальной инструкции Flet для Android](https://flet.dev/docs/publish/android/).

## Как устроено обучение

При первом запуске приложение предлагает выбрать русский или румынский язык интерфейса.

1. Выберите тематическую категорию.
2. Нажмите «Учить новые слова» и пройдите карточки.
3. После карточек выберите правильный перевод каждого слова.
4. Правильно отвеченное новое слово отмечается как выученное.
5. Используйте повторение и ежедневную подборку, чтобы закреплять материал.

Обычная сессия повторения категории содержит до 6 слов, а общее повторение — до 10. Ежедневная сессия становится доступна после изучения как минимум 20 слов и сохраняется, если закрыть её до завершения.

## Структура проекта

```text
gagauzium/
├── main.py                 # интерфейс и логика приложения
├── words_data.json         # словарь гагаузских слов
├── user_stats.json         # прогресс при прямом запуске из исходников
└── assets/
    └── fast_check.png      # иконка быстрого повторения
```

### Формат словаря

Каждая запись в `words_data.json` имеет следующий вид:

```json
{
  "id": 1,
  "ru": "я",
  "ro": "eu",
  "gag": "bän",
  "category": "Местоимения",
  "learned": false
}
```

Поле `id` должно быть уникальным. Исходный словарь не содержит пользовательского прогресса: для всех записей `learned` имеет значение `false`. Фактический статус изучения хранится отдельно в `user_stats.json` или в постоянном хранилище Android-приложения.

## Данные и резервное копирование

Все данные остаются на устройстве пользователя. Файл `user_stats.json` содержит:

- выбранный язык интерфейса;
- статус изучения каждого слова;
- количество правильных и неправильных ответов;
- дату последнего появления слова;
- серию занятий и состояние ежедневного повторения.

При прямом запуске через `python main.py` прогресс хранится в `user_stats.json` рядом с исходниками. В собранном Android-приложении Flet помещает его в приватное постоянное хранилище приложения. Оно сохраняется при установке обновлений с теми же package ID и подписью, но удаляется при удалении приложения или очистке его данных.

## Разработка

Вся логика приложения пока находится в `main.py`. При изменении структуры словаря сохраняйте UTF-8, не переиспользуйте существующие идентификаторы слов и проверяйте соответствие категорий карте `category_map`.
